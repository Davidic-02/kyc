# Security Policy

## Reporting a Vulnerability

Please report potential security vulnerabilities privately to the maintainers.

Include:

- affected component(s)
- reproduction steps or proof of concept
- potential impact
- suggested mitigation (if known)

Do not open public issues for undisclosed vulnerabilities.

## Response Process

- We acknowledge reports as quickly as possible.
- We validate and triage severity.
- We work on a fix and coordinate disclosure timing.

## Scope

This policy applies to the source code and related project assets in this repository.
