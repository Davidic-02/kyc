# Contributing

Thank you for contributing to KYC.

## Development Setup

1. Install Flutter SDK.
2. Clone the repository.
3. Run:

```bash
flutter pub get
flutter analyze
flutter test
```

## Coding Guidelines

- Follow the feature-first clean architecture structure.
- Keep changes scoped to one concern per pull request.
- Add/update tests for logic changes.
- Update documentation when structure or workflow changes.

## Pull Request Process

1. Create a branch from `main`.
2. Use clear commit messages.
3. Ensure analysis and tests pass locally.
4. Fill out the PR template.
5. Request review.

## Review Expectations

Reviewers focus on:

- correctness and regressions
- architecture alignment
- readability and maintainability
- test and docs coverage

## Reporting Bugs

Use the bug issue template and provide reproducible steps.

## Suggesting Features

Use the feature request template and include impact and acceptance criteria.
